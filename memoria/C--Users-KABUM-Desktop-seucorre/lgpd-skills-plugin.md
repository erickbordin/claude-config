https://github.com/goul4rt/lgpd-skills (MIT, v1.2.0). Instala com `/plugin marketplace add goul4rt/lgpd-skills` e `/plugin install lgpd-skills@lgpd-skills`. Maestro `lgpd-audit` + 18 sub-skills; grava artefatos em `.lgpd/`.

Avaliado em 06/11/2026: só markdown no plugin do Claude, sem hooks. Exemplos em Next.js/Prisma (adaptar para Spring). Não cobre CDC (Termos, assinatura, arrependimento) e não substitui advogado.

Úteis no seucorre: lgpd-legal-basis (dado de saúde, art. 11), lgpd-international-transfer (Stripe, Google, Resend, Gemini), lgpd-retention-erasure (prazo do contador), lgpd-privacy-policy, lgpd-incident-response, lgpd-dpo-encarregado.
